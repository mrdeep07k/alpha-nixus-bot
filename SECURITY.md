# 🔒 Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 2.x | ✅ |
| 1.x | ❌ |

## 🚨 Vulnerability report karna

Agar koi security issue mile — **public issue mat banao**.
Seedha maintainer ko contact karo: GitHub par [@mrdeep07k](https://github.com/mrdeep07k)

Report me ye daalo:
- Problem ka description
- Reproduce karne ke steps
- Kitna impact ho sakta hai

Hum 72 ghante ke andar reply karne ki koshish karenge.

## 🛡️ Safe usage tips

| Do ✅ | Don't ❌ |
|---|---|
| Password `.env` / panel env vars me rakho | Password code me hardcode mat karo |
| `.env` ko `.gitignore` me rakho (already hai) | `.env` GitHub par commit mat karo |
| Discord webhook URL secret rakho | Webhook URL public repo/screenshot me mat dikhao |
| Bot ka password unique rakho | Apna asli account password mat use karo |

> ⚠️ Agar galti se webhook URL public ho jaye — Discord me jaake usse **delete** karo aur naya banao.

## ⚖️ Responsible use

Ye bot sirf **apne server** par ya jahan owner ki permission ho wahan use karo.
Kisi server ke rules todna ya ban evade karna users ki apni zimmedari hai — maintainer iske liye responsible nahi.
