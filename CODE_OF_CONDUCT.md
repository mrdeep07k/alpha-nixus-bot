# 🤗 Code of Conduct

## Hamara vaada

Is project me sab ka swagat hai — chahe tum beginner ho ya expert, kisi bhi background se ho.

## Achhi baatein ✅

- Dusron ki help karo, chahe sawaal simple ho
- Feedback politely do
- Galti maano aur seekho
- Hinglish / English / koi bhi bhasha — communication important hai, grammar nahi

## Bardasht nahi ✋

- Gaali-galauch, personal attacks, harassment
- Kisi ki caste, religion, gender, ya background par comment
- Dusron ki private info share karna
- Spam ya self-promotion

## Enforcement

Koi problem ho to maintainer [@mrdeep07k](https://github.com/mrdeep07k) ko report karo.
Violation par warning, comment removal, ya permanent ban ho sakta hai.
